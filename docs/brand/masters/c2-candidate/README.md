# C2 vector candidate

This directory contains the controlled vector candidate for the selected C2 Forged Automaton direction.

## Files

- `sigidi-mark.svg`: canonical monochrome mark geometry.
- `sigidi-mark-small.svg`: simplified mark for favicon and notification sizes.
- `sigidi-wordmark.svg`: canonical custom uppercase wordmark.
- `sigidi-lockup.svg`: review lockup assembled from the mark and wordmark geometry.
- `sigidi-app-icon-production.svg`: review production icon treatment.

## Color values

- Iron black: `#171717`
- Warm off-white: `#F4F0E8`
- Ember orange: `#D65A32`

Contrast against iron black:

- Warm off-white: `15.77:1`
- Ember orange: `4.58:1`

# SIGIDI shortlist refinements: round 2

These sheets refine the selected B3, C2, and D1 concepts. They are raster concept images, not production vector assets.

Each prompt requested:

- A cleaned monochrome mark that preserves the selected concept.
- An iron-black production icon with a warm off-white mark.
- One restrained ember-orange accent on the axe blade.
- A horizontal lockup with the exact uppercase word `SIGIDI`.
- One broad wedge-shaped blade, narrow tang, and plain shaft.
- No face, costume, sacred symbol, double-headed axe, texture, gradient, or heavy depth.
